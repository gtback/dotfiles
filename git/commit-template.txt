# Subject
# * scope: imperative description — aim for ~65-70 chars, incl. the scope
# * Scope is the subsystem or area touched (vscode, git, brew)
# * Multiple scopes: use a broader one, or list them comma-separated;
#   use `global` or `all` only if it touches the entire tree
# * Capitalized, imperative mood ("Add", not "Added" or "Adds"), no period
#
# Body
