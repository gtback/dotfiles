# AGENTS.md

Guidance for coding agents working in this dotfiles repo.

## Agent config is symlinked

`~/.claude/CLAUDE.md` is a symlink to `claude/CLAUDE.md` in this repo, and
`~/.config/agents` is a symlink to `agents/`. Edit the files here, not through
the symlinks. Changes show up as uncommitted changes in this repo.

- `agents/`: instructions shared by all agents. `claude/CLAUDE.md` pulls them
  in with `@` imports (always loaded) or a "read this file when ..." pointer
  (loaded on demand).
- `claude/CLAUDE.md`: global Claude Code instructions.
- `claude/settings.json` is generated by `claude.render` from settings layers,
  not symlinked. See `install.sh`.
